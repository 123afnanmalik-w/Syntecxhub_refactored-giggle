# Encrypted Chat App

A client/server chat application built with TCP socket communication where all messages are secured using AES symmetric encryption before transmission[cite: 1].

## Features
* **TCP Socket Communication:** Reliable real-time connection between a central server and multiple clients[cite: 1].
* **AES Encryption:** End-to-end symmetric encryption ensuring messages remain confidential[cite: 1].
* **Key & IV Management:** Secure pre-shared key handling and safe initialization vector (IV) usage[cite: 1].
* **Multi-Client Concurrency & Logging:** Supports multiple simultaneous clients with built-in message activity logging[cite: 1].
